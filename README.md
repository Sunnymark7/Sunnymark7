## 👋 About

我是 Vic，一名偏爱软硬件闭环的工程实践者。我的项目通常从真实传感器出发，跨过固件、协议、算法和可视化，最后落到一个能被测试、被操作的系统上。

目前重点在触觉交互、脑机接口、嵌入式采集与科研仪器软件。这里展示的是经过整理的工程脉络，不是工具徽章或统计数字的堆叠。
